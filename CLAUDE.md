# CLAUDE.md — быстрый вход в проект «Мимоходом»

Нативное Android-приложение на Java, `K:\Projects\fast`, пакет `app.fastnotes`, GitHub `Ux1ew1/Mimohodom`. Общается с пользователем по-русски. Подробности — в `AGENTS.md` (поведение по версиям), `README.md` (секция на версию), `VERIFICATION.md` (что проверено и что НЕ проверено на устройстве), `docs/AGENT.md` (консольный мост). Не изучай проект с нуля — начни с этих файлов и этой памятки.

## Рабочий цикл пользователя
Я делаю этап → сборка → тесты → локальный коммит → отправляю APK (`dist/mimohodom-<версия>-debug.apk`, SendUserFile) → пользователь тестирует на телефоне и просит следующий шаг. Каждый релиз обновляет `AGENTS.md` (версия и поведение), `README.md`, `VERIFICATION.md`. Для установки поверх: `versionCode` растёт, `applicationId` и отладочный ключ те же. Перед выдачей APK проверить версию и подпись.

## Архитектура (кратко)
- UI целиком в коде, без XML: `MainActivity` (~5400 строк; помощники `text/button/row/column/gap/pad/shape/ripple/secondary/section/toggle/settingsRow`, `Glyph`). Вкладки: 0 «Заметки», 1 «Записать» (старт), 2 «ИИ-чат»; настройки — индекс 3 (хаб из 4 разделов: ИИ, напоминания, помощник, приложение; автосохранение).
- Данные: `Store` (SQLite + FTS), `Note`, `ManagerStore`, `FolderStore`. Новые столбцы — только в конец; миграции идемпотентны (`hasColumn`); `Store.onCreate` должен сохранять ровно 8 inline-вызовов `execSQL` (на это опираются node-тесты, извлекающие SQL из `Store.java`).
- ИИ: `Polza` (облако, ключ в `Secrets`/Keystore), `ChatRunner`, `LocalLlm` (GGUF через JNI, `native/llama.cpp` — подмодуль) + `AiCore`/`AiCorePrompt` (Gemini Nano, только на переднем плане). `LocalLlm.cloudBackground(c)` = фоновые функции идут через Polza при выключенном локальном режиме или AICore; при GGUF приостановлены.
- Фон: `BackgroundAnalysis`, `ManagerJob`, `ReviewBudget` (дневной лимит 4, снимается пользователем), `SummaryRunner`, `CheckInJob` (помощник сам пишет вопросы), `Reminders`/`ReminderReceiver`/`BootReceiver`.
- Чистая Java с JVM-тестами (без Android — сохраняй это): `ReminderPolicy`, `ImageCleanup`, `ShareParser`, `CropMath`, `ImageList`, `CheckIn`, `ChatMemo`, `FolderPolicy`, `FolderSuggestion`, `VideoAnalysis`, `VideoMerge`, `YoutubeLink`, `AiCorePrompt`, `AgentCommand`.
- **Видео YouTube (0.9.0):** ссылка из «Поделиться» или вставленная в новую заметку (только ссылки) → `YoutubeLink` → окно с ценой (`offerVideoSummary`) → `VideoRunner` → один запрос `chat/completions` с частью `{"type":"video_url","video_url":{"url":…}}` к модели `videoModel` (настройка «Модель для видео YouTube», по умолчанию `google/gemini-2.5-flash-lite`, ролик ≈10 минут ≈ 2 ₽; ожидание ответа 240 с через `Polza.request(path,key,body,timeout)`). Ответ — строки «ЗАГОЛОВОК / КРАТКО / ГЛАВНОЕ / ТЕМЫ» (`VideoAnalysis`); заметка кончается `Видео: https://www.youtube.com/watch?v=ID`, по этой строке ищутся повторы (`Store.noteIdContaining`) и кандидаты (`videoNotes`). Субтитры YouTube без токена приходят пустыми, обход через клиент Android не использовать. Новые модели Polza.AI (`gemini-3.8-flash`) резервируют >100 ₽ → 402. Платная проверка с ключом: `scripts/probe-video-polza.ps1 [модель] [ссылка]`. Очередь запросов не переживает закрытие процесса.
- **Общая заметка по теме:** `VideoMerge` (похожесть `TopicSelection.similarity` ≥ 0,3; текст «Общее по теме» + разделы `━━ название ━━`, до 12), `VideoRunner.merge` (текстовый запрос), `Store.mergeVideo` (транзакция по версиям обеих заметок). Диалоги идут одной очередью `askNext`: `mergeQueue` → `folderQueue`, общий флаг `mergeAsking`.
- **Папки:** `notes.folder` (столбец 16, SQLite v8, `Store.addFolders`) и таблица `folders(id,name,key UNIQUE,created,auto)`. Заметка — не больше чем в одной папке; 0 = только «Все заметки» (вкладка показывает всё). `FolderStore.move` переносит и участников стопки; `Store.newNoteFolder` (static) — папка для новых заметок. Интерфейс: `folderChips`, `chooseFolder`, `askFolderName`, `editFolder` в редакторе; экспорт версии 4. Автопапки: `FolderSuggestion` по `metadata.ai.topics` (≥2 заметок или существующая папка), без новых запросов, создаёт только после подтверждения (`showFolderSuggestions`, `askNextFolder`, скрытые темы `folderDismissed`).
- Напоминания: точные будильники при `SCHEDULE_EXACT_ALARM`, пропущенные до 7 дней, откладывание, повторы (`repeat_mode`, `lead_minutes`), утренняя сводка, каналы `reminders/suggestions/manager/digest/checkin`. Кто что делает (после исправлений B1/B2): `schedule` — заново ставит только основной будильник (запуск, перезагрузка), отложенное оповещение и показанное уведомление не трогает; `scheduleEdited(before, after)` — после правки заметки, снимает отложенное только если событие перенесли/убрали/сменили повтор; `cancel` — при удалении. Повторяющаяся серия передвигается `advanceWhenDue` в момент самого события (`ReminderPolicy.advanceDue`), а не при предупреждении «за N минут»: до события стоит будильник на его время, по нему `ReminderReceiver` передвигает серию.
- Редактор (B4): `persistEditedNote` сравнивает поля со снимком `editorBase` (заметка при загрузке, берётся в `editor()`, если нет черновика `draft.<id>.title`) и пишет только поля, изменённые пользователем, — иначе затрёт название/предложение от фоновой ИИ и итог помощника. `openNote` из открытой заметки сохраняет её и не пишет `returnPage = "edit"` (B3).
- Картинки: `files/images/<UUID>.jpg`; до 8 на заметку в одном столбце `notes.image` через запятую — всегда разбирать `ImageList.parse`. Любую новую ссылку на картинку добавляй в `ImageFiles.referenced`, иначе очистка удалит файл. Камера: `ACTION_IMAGE_CAPTURE` + `FileProvider` (`${applicationId}.files`), без CAMERA permission. Чат — по-прежнему одна картинка (`chatImage.<id>`).
- Мост агента: код только в `app/src/agent` (не должен попасть в debug/release). Новым кнопкам без текста задавай `setContentDescription`. Агент-тестировщик `app-tester` проверяет приложение на устройстве через `scripts/agent.mjs`.

## Git и окружение
- Команды git: `git -c safe.directory=K:/Projects/fast ...`. Автор коммита: переменные окружения `GIT_AUTHOR_NAME/EMAIL`, `GIT_COMMITTER_NAME/EMAIL` = `Claude` / `noreply@anthropic.com` (конфиг не менять). Коммиты заканчивай строкой `Co-Authored-By` из системного напоминания текущего сеанса (модель бывает разной). Перед коммитом смотри `git diff --cached`, добавляй только файлы задачи. APK, `.tools`, ключи, `reports/` в Git не кладём.
- `gh` не установлен: Actions запускай на сайте. Сборка на pull request подписана временным ключом и поверх установленного приложения не встанет, нужна ручная («Run workflow») или на `main`.
- Инструмент Edit срезает хвостовой пробел в строках: в `.ps1` из-за этого склеивались аргументы; длинные списки файлов держи массивом по одному на строку.
- HTTPS к GitHub нестабилен (TLS handshake) — повторяй push/fetch.
- Правки файлов скриптами: определяй CRLF/LF (в индексе LF, в рабочем дереве по-разному), не создавай `\r\r\n`. Длинные Python-скрипты не вставляй в heredoc Bash — пиши в scratchpad через Write и запускай.
- Линт: пользовательские View от `ImageView` требуют `@SuppressLint("AppCompatCustomView")`. Строки `e: … incompatible version of Kotlin` от ML Kit в выводе `lintDebug` — старый шум, сборка при этом успешна.
- Кириллица в строковых литералах `.ps1` без BOM ломает разбор в PS 5.1 — строки в скриптах пиши по-английски. `python` в Bash может зависнуть на заглушке Windows Store — для мелких правок Edit/`node -e`.
- В этой папке иногда параллельно работает другой сеанс Claude и коммитит в текущую ветку (даже в те же файлы, включая этот). Перед правкой общего файла перечитай его, перед коммитом проверь `git status`/`git log -3`.
