# Мимоходом для компьютера: что сделано

Документ описывает порт приложения на Windows и macOS: этап 1 (версия 0.10.0) и первую часть этапа 2 — ИИ-чат (компьютер 0.11.0). Протокол обмена с телефоном — в `docs/SYNC.md`, команды запуска — в `desktop/README.md`, что проверено и что нет — в `VERIFICATION.md` (разделы «Компьютер 0.11.0» и «Версия 0.10.0»). **Этот файл дополняется после каждой части работы над компьютерной версией.**

## Решения

- **Стек:** Tauri 2. Ядро на Rust, интерфейс на HTML/JS/CSS без сборщика. Один набор исходников для Windows и macOS.
- **Синхронизация:** напрямую по Wi-Fi между телефоном и компьютером, без сервера и облака, с шифрованием. Сопряжение по QR-коду.
- **Порядок работы:** по этапам. Этап 1 (сделан): ядро, синхронизация, заметки, поиск, папки, картинки. Этап 2: ИИ-чат (сделан, 0.11.0), фоновый помощник, видео YouTube, синхронизация чатов и стопок. Этап 3: уведомления о напоминаниях, календарь, подписанные установщики.
- **Ключ Polza.AI:** на каждом устройстве свой; на компьютере хранится в системном хранилище (Диспетчер учётных данных Windows, Связка ключей macOS) и не передаётся при сопряжении.
- **Версии:** компьютерная программа нумеруется отдельно от Android, когда меняется только она (0.11.0 — компьютер, Android остаётся 0.10.2).

## Что умеет компьютерная версия

- Список заметок и сетка, поиск (SQLite FTS5, те же правила разбора запроса, что на телефоне).
- Папки: создание, переименование, удаление, перенос заметки; боковая панель.
- Редактор: название, текст, до 8 картинок, напоминание, повтор, «за N минут», папка. Автоназвание по тексту, как на телефоне.
- Тёмная тема и режим «как в системе».
- Экспорт заметок в файл.
- Настройки синхронизации: включение, код сопряжения (QR и строка), список подключённых устройств, «Обменяться сейчас», забыть устройство, имя этого компьютера.
- **ИИ-чат (0.11.0):** список чатов, переписка, ответы по заметкам со ссылками на них и строками источников, предложение заметки с правкой перед сохранением, немедленное сохранение по просьбе «создай заметку», пачка напоминаний по датам с выбором строк, до 6 картинок в сообщении (кнопка, вставка, перетаскивание), память картинок чата, заметка по картинке, кеш ответов на сутки, ручной повтор после ошибки без дубля, переименование и удаление чата.
- **Настройки ИИ:** ключ, баланс, модель чата (список с Polza.AI), модель для картинок, длина ответа.

Напоминания на компьютере хранятся и обмениваются с телефоном, но уведомлений нет (этап 3). Фонового помощника и видео YouTube пока нет (этап 2, следующие части). Локальных моделей (Gemini Nano, GGUF) на компьютере не будет.

## Устройство `desktop/`

| Путь | Назначение |
|---|---|
| `core/src/store.rs` | SQLite (схема v2): заметки, папки, tombstones, узлы, настройки, индекс поиска; с v2 — чаты, сообщения, кеш ответов ИИ. Порт `Store.save`, `candidates`, `applyMetadata`, `acceptDraft`, `acceptReminders` с Android. |
| `core/src/policy.rs` | Порты правил из Android: папки, список картинок, автоназвание, разбор поискового запроса, метаданные. |
| `core/src/sync/crypto.rs` | HKDF-SHA256 и AES-256-GCM. |
| `core/src/sync/engine.rs` | Выбор изменений (`collect`) и слияние (`apply`). |
| `core/src/sync/server.rs` | HTTP-сервер (порт 47616) и UDP-обнаружение (47615). |
| `core/src/sync/client.rs` | Обмен с телефоном или другим компьютером, обнаружение адреса. |
| `core/src/sync/pairing.rs` | Строка сопряжения, одноразовый код, QR. |
| `core/src/ai/text.rs` | Чистая логика чата: выбор заметок, отрывки, подсказки ИИ, черновик, пачка напоминаний, картинки чата. Тексты для модели дословно с телефона. |
| `core/src/ai/chat.rs` | Сборка запроса и разбор ответа, заметка по картинке, фоновый запуск (один запрос за раз). |
| `core/src/ai/polza.rs` | HTTP к Polza.AI, тексты ошибок, список моделей, баланс. |
| `core/src/ai/keys.rs` | Ключ в системном хранилище (`keyring`) или в памяти (тесты, отладка). |
| `core/src/api.rs` | `dispatch(cmd, args)`: все команды интерфейса; фоновый обмен раз в 2 минуты. |
| `core/examples/` | `dev` (интерфейс в браузере) и `headless` (для проверки обмена без окна). |
| `src-tauri/` | Оболочка: одна команда `rpc`, диалог сохранения файла. |
| `ui/` | Интерфейс; палитра взята с Android. |

Данные хранятся в папке приложения пользователя: база и каталог `images/`.

## Синхронизация

Кратко (подробно — `docs/SYNC.md`):

- У каждого устройства свой идентификатор. Компьютер работает и сервером, и клиентом, телефон — только клиентом.
- Сопряжение: компьютер показывает строку `mimohodom://pair?...` (QR). Код действует 10 минут, срабатывает один раз, после трёх неверных попыток сгорает. Из общего секрета выводится ключ; тела запросов шифруются AES-256-GCM, защищены от повтора (метка времени и идентификатор запроса).
- Синхронизируются заметки, папки, удаления (tombstones) и картинки.
- Слияние: побеждает более поздняя правка (гибридные логические часы). Если заметку изменили на обоих устройствах до обмена, локальная версия сохраняется отдельной заметкой «… (копия при конфликте)». Удаление не отменяет более позднюю правку на другом устройстве.
- Папки на разных устройствах сопоставляются по идентификатору, который считается из названия, поэтому одноимённые папки сходятся.
- Картинки передаются отдельными запросами по именам файлов, которых не хватает на одной из сторон.
- ИИ-чат, стопки и итоги помощника пока не синхронизируются.

## Что изменено на Android (0.10.0)

- SQLite версии 9: в заметках и папках появились идентификатор и метки синхронизации; таблицы узлов и удалений. Миграция из 8 идемпотентна. Триггеры реагируют только на содержательные изменения, поэтому фоновая работа ИИ не перебивает чужую правку.
- Новые классы: `SyncCrypto`, `SyncRecord`, `SyncPairing`, `SyncStore`, `SqliteSyncStore`, `MiniHttp`, `SyncClient`, `PeerSync`.
- Экран «Настройки → Синхронизация»: подключение компьютера (QR через системный сканер Google или ввод строки), список устройств, «Обменяться», «Забыть».
- Обмен идёт при открытии и сворачивании приложения (не чаще раза в 90 секунд). После принятых заметок переставляются напоминания и запускается синхронизация с календарём.

## Проверки

- `cargo test -p mimo-core` в `desktop/`: 30 модульных и 5 сквозных тестов (3 — синхронизация, 2 — ИИ-чат против локальной заглушки Polza.AI в `core/tests/chat.rs`).
- Ручная проверка чата без оплаты: `node tests/fake-polza.cjs 5199`, затем пример `dev` с переменной `MIMO_AI_BASE=http://127.0.0.1:5199/api`.
- `scripts/test-sync.ps1`: Java-тесты протокола, SQL-тест триггеров на настоящем SQLite (по SQL, вынутому из `Store.java`) и сквозной тест, где настоящий Java-клиент обменивается с Rust-сервером.
- В `.github/workflows/android.yml` добавлены эти тесты и задача `desktop`, которая собирает установщики на Windows и macOS. Задача ни разу не запускалась.

## Не проверено

- Обмен настоящего телефона с настоящим компьютером по Wi-Fi; поиск адреса в разных сетях (изоляция клиентов, VPN, брандмауэр).
- Сканер QR и экран синхронизации на телефоне; миграция 8 → 9 на Android SQLite.
- Сборка на macOS; установщики NSIS/MSI/DMG; подпись и нотаризация.
- Большие объёмы данных.
- ИИ-чат с настоящим ключом Polza.AI на компьютере (только заглушка), хранение ключа в системном хранилище, окно Tauri с чатом, вставка картинки из буфера в настоящем окне.
