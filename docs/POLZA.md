# Работа с Polza.AI в «Мимоходом»

[Polza.AI](https://polza.ai) — облачный сервис, через который приложение обращается к языковым моделям. Он нужен для ИИ-чата, анализа картинок и видео YouTube, фоновых проверок заметок, помощника с вопросами и общих заметок по теме. Без ключа Polza.AI приложение остаётся заметками с напоминаниями и поиском; локальные режимы (Gemini Nano, GGUF) описаны в [README.md](../README.md).

Документ описывает состояние на версию 0.9.4. Что из этого проверено и что нет — в разделе «Что не проверено» и в [VERIFICATION.md](../VERIFICATION.md).

## Быстрый старт

1. Создайте аккаунт на polza.ai, выпустите API-ключ и пополните баланс.
2. В приложении: «Настройки» → «ИИ» → вставьте ключ. Настройки сохраняются сами.
3. Нажмите «Выбрать из каталога моделей» (или впишите ID вручную, например `openai/gpt-4o-mini`) и выберите модель для обычного чата.
4. Нажмите «Обновить баланс», чтобы убедиться, что ключ принят.
5. Откройте «ИИ-чат» и отправьте сообщение. При первом запросе приложение объяснит, какие данные уходят в облако, и попросит согласие.

Для картинок и видео отдельные модели можно не задавать: есть значения по умолчанию (таблица ниже).

## Настройки

| Поле в приложении | Ключ в `SharedPreferences` | По умолчанию | Для чего |
|---|---|---|---|
| Ключ API | `Secrets` (Keystore) | — | Авторизация во всех запросах |
| ID модели | `model` | пусто, нужно выбрать | Чат, фоновые проверки, менеджер, выжимки, вопросы помощника, общая заметка по видео |
| Модель для картинок | `imageModel` | `google/gemini-2.5-flash` | Картинки в чате и в заметках |
| Модель для видео YouTube | `videoModel` | `google/gemini-2.5-flash-lite` | Анализ ролика по ссылке |
| Максимальная длина ответа | `maxTokens` | 600 | «Дополнительно»: 300 / 600 / 1200 токенов, только для чата |

Поля картинок и видео видны в режиме Polza.AI. Если поле пустое, берётся значение по умолчанию. Модель для обычного текста («ID модели») без выбора не заработает: фоновые переключатели и чат требуют и ключ, и модель.

## Где хранится ключ

- Ключ шифруется AES-GCM, ключ шифрования лежит в Android Keystore под алиасом `polza` (`Secrets.java`).
- Ключ не вшит в APK и не попадает в экспорт заметок.
- Автоматическое резервное копирование приложения отключено.
- Пустое поле ключа стирает сохранённое значение.
- Заметки, чаты и картинки лежат в приватной SQLite-базе и в `files/images` без отдельного шифрования.

## Как приложение обращается к API

Клиент — `Polza.java`, обычный `HttpURLConnection`, без сторонних библиотек.

| Что | Запрос |
|---|---|
| Чат и все ИИ-функции | `POST https://polza.ai/api/v1/chat/completions` |
| Каталог моделей | `GET https://polza.ai/api/v1/models?type=chat` |
| Баланс | `GET https://polza.ai/api/v2/balance` (поля `amount` и `available`) |

Общие правила клиента:

- Заголовок `Authorization: Bearer <ключ>`, тело — JSON в UTF-8.
- Таймаут соединения 15 с. Ожидание ответа: 60 с по умолчанию, 180 с для чата с картинками, 240 с для видео.
- Редиректы не выполняются. Ответ больше 4 МБ отклоняется.
- Повторов платных запросов нет: при ошибке пользователь повторяет вручную.

Ошибки показываются пользователю по коду ответа:

| Код | Сообщение |
|---|---|
| 401, 403 | Проверьте API-ключ и доступ к модели в настройках |
| 402 | Недостаточно средств на балансе Polza.AI |
| 429 | Превышен лимит запросов, попробуйте позже |
| другие | Polza.AI вернул ошибку с кодом, повторите позже |

Сообщение «Запрос мог быть оплачен» появляется при таймауте: сервер мог принять запрос и списать деньги, поэтому автоповтора нет.

## Что и когда уходит в Polza.AI

| Функция | Когда запускается | Что отправляется | Модель |
|---|---|---|---|
| ИИ-чат | Сообщение пользователя | До 8 заметок и 12 000 символов их текста (фрагменты около совпадений), до 6 последних сообщений и 6 000 символов истории | `model` |
| Картинки в чате | Сообщение с вложением или последующие сообщения того же чата | До 6 последних картинок (≈6 МБ) как `image_url` с data URL | `imageModel` |
| Заметка по картинке, «Описать и добавить» | Явное действие, перед отправкой приложение спрашивает | Выбранные картинки (до 2048 px, JPEG ≤ 2 МБ) | `imageModel` |
| Видео YouTube | Ссылка из «Поделиться» или вставленная в новую заметку, после окна с ценой | Ссылка как часть `video_url` | `videoModel` |
| Общая заметка по теме | Подтверждение в диалоге объединения | Тексты разделов обеих заметок (до 12 разделов) | `model` |
| Фоновая проверка (названия, напоминания, метаданные, поиск объединений) | Примерно раз в 6 часов в фоне либо «Проверить сейчас» | Фрагменты новых и изменённых заметок | `model` |
| Менеджер заметок | Примерно раз в 6 часов, с сетью и зарядом | Выбранные записи и связанные через локальный индекс | `model` |
| Выжимка стопки | Кнопка «Подготовить выжимку» | Полные тексты выбранных записей, до 8 фрагментов и 12 000 символов на запрос | `model` |
| Вопросы помощника (`CheckIn`) | Сам помощник пишет вопросы о планах | Короткий запрос, ответ ≤ 220 токенов | `model` |

Фоновые функции, менеджер, ручной обзор и выжимки идут через Polza.AI, пока локальный режим выключен либо выбран Gemini Nano. При GGUF облачные задания не ставятся (`LocalLlm.cloudBackground`).

### Согласие

Приложение просит явное согласие перед первой отправкой данных: в чате (`consent`) и перед ручным обзором («Проверить сейчас», `manualReviewConsent`). Для менеджера и фоновых переключателей согласие даётся в разделе «Помощник заметок». Фоновая работа по умолчанию выключена.

## Как ограничены расходы

- **Выборка, а не архив.** Заметки отбираются локальным ранжированием без платных эмбеддингов. Вопрос ограничен 2 000 символами.
- **Кеш чата.** Ответ хранится 24 часа (до 100 записей). Ключ кеша учитывает модель, контекст, вопрос, историю, дату и ревизию заметок. Одинаковый вопрос получит ответ без нового запроса, и в подписи будет «Из кеша».
- **Лимит фона.** Фоновая проверка, менеджер и выжимка стопки делят общий лимит: не больше 4 пакетов в сутки (`ReviewBudget`). Пользователь может снять лимит в настройках. Чат и картинки в этот лимит не входят и оплачиваются отдельно.
- **Двойная отправка заблокирована.** Запрос переживает поворот экрана, но не закрытие процесса.
- **Длина ответа.** Чат: 300/600/1200 токенов по настройке. Фоновые проверки, менеджер и выжимки: 1200. Картинки: 1400 (одна) или 2000 (несколько).
- **Стоимость.** После ответа приложение показывает токены и `usage.cost_rub`, если API его вернул. Лимит токенов не гарантирует фиксированную цену: тарифы зависят от модели.

Ориентир по видео: ролик около 10 минут на модели по умолчанию стоит порядка 2 ₽. Это замер из разработки, а не гарантия.

## Видео YouTube: что важно знать

- Запрос один: `chat/completions` с частью `{"type":"video_url","video_url":{"url":"<ссылка>"}}`. Субтитры не скачиваются, обходов через клиент Android нет.
- Модель должна понимать видео по ссылке (Gemini). Ответ разбирается по строкам «ЗАГОЛОВОК / КРАТКО / ГЛАВНОЕ / ТЕМЫ».
- Новые модели Polza.AI (например, `gemini-3.8-flash`) резервируют на балансе больше 100 ₽ и без этого дают ошибку 402. Поэтому по умолчанию стоит `gemini-2.5-flash-lite`.
- Повторная ссылка на уже сохранённый ролик новый запрос не создаёт: заметка ищется по строке `Видео: https://www.youtube.com/watch?v=ID`.
- Очередь роликов не переживает закрытие процесса.

## Проверка без телефона

Контрактные тесты не обращаются к сети и не тратят деньги (запросы подменяются):

```powershell
.\scripts\test-polza.ps1
```

Скрипт собирает и запускает `PolzaTest`, `AnalysisTest`, `VisionTest` и `MetadataTest`. Тесты также входят в `.github/workflows/android.yml`. Ключ для CI не нужен.

Платная проверка видео с реальным ключом (до трёх коротких запросов, ключ вводится скрыто и нигде не печатается):

```powershell
.\scripts\probe-video-polza.ps1 [модель] [ссылка]
```

Без аргументов берётся первая модель Gemini вида flash из каталога и ролик на 19 секунд.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| «Проверьте API-ключ…» | Ключ без пробелов и кавычек; у ключа есть доступ к выбранной модели; ID модели написан точно как в каталоге |
| «Недостаточно средств» (402) | Баланс в настройках; для новых моделей Polza.AI может требовать запас на балансе больше цены запроса |
| «Превышен лимит запросов» (429) | Подождать и повторить вручную |
| Пустой ответ модели | Выбрать другую модель; для картинок нужна модель с поддержкой изображений |
| «Некорректный ответ модели» на картинке | Модель не вернула JSON, нужна модель посильнее |
| Фоновые проверки не идут | Заполнены ключ и модель, включён «Фоновый помощник ИИ», режим не GGUF, не исчерпан лимит 4 в сутки, у Android есть сеть и заряд |
| Баланс «недоступен» | Ключ и интернет, затем «Обновить баланс» |

## Что не проверено

Реальные вызовы Polza.AI с ключом в рамках 0.9.4 не выполнялись: контрактные тесты используют подменённые ответы. В частности, не проверены:

- существование и цена `google/gemini-2.5-flash` для картинок в Polza.AI (модель выбрана без проверки с ключом);
- приём нескольких `image_url` и запроса до ≈8 МБ;
- качество ответов по картинкам и повтор запроса с картинками после ошибки;
- анализ видео на актуальной цене и модели, кроме замера в разработке;
- работа фона (`JobScheduler`) с живым сервисом на телефоне.
