# Баллы внимания (эксперимент)

Черновик правил для экспериментальной функции: у заметки есть запас «внимания» помощника —
баллы от 0 до 8. Пока баллы есть, ИИ работает с заметкой как обычно (фоновая проверка,
предложения, вопросы «Как продвигается?»). На нуле помощник оставляет заметку в покое.
Функция выключена по умолчанию и включается в настройках.

## 1. Зачем

Помощник сейчас работает со всеми заметками одинаково: проверяет, предлагает, спрашивает.
Старые и неинтересные записи получают столько же внимания, сколько живые дела. Баллы — способ
перестать донимать пользователя тем, что он игнорирует, и не тратить платные запросы на
мертвые заметки.

## 2. Хранение

- `notes.attention INTEGER NOT NULL DEFAULT -1` (SQLite 20).
- `-1` — «баллы ещё не назначены»: функция выключена или заметка создана до неё. Такие заметки
  обслуживаются как раньше.
- `0..8` — текущий запас. Назначается при создании заметки, если функция включена.
- Как `suggestion_times`: в обмен не идёт, триггеров синхронизации нет, изменение баллов не
  сдвигает `sync_seq` и не помечает заметку изменённой для компьютера.

## 3. Назначение при создании (5–8)

Базовые 5 + бонусы за признаки важности:

| Признак | Баллы |
|---|---|
| База | 5 |
| Класс заметки `event` (дата/событие) | +1 |
| Класс `complex` или есть план | +1 |
| Есть напоминание | +1 |

Итого 5–8. Класс известен не сразу (его ставит фоновая проверка), поэтому при создании
ставится 5 + «есть напоминание», а бонус за класс добавляет первая проверка (один раз).

## 4. Минус-баллы

| Событие | Баллы |
|---|---|
| Заметке больше недели и за неё ни разу не брались (нет открытий/правок) | −1 в неделю |
| Пользователь нажал «Отклонить» на предложении ИИ | −1 |
| Вопрос помощника остался без ответа 3 дня | −1 |
| «Как продвигается?» → «Не актуально» | −2 |
| «Как продвигается?» → «Отложить» два раза подряд | −1 |

Потолок списаний — не чаще одного минуса в сутки на заметку (суммируя все правила), чтобы
серия неприятных событий не обнуляла заметку за день.

## 5. Плюс-баллы (интерес пользователя)

| Событие | Баллы |
|---|---|
| Открыл заметку | +1 (не чаще раза в сутки) |
| Отредактировал | +1 (не чаще раза в сутки) |
| Ответил на вопрос помощника | +1 |
| Принял предложение ИИ («Использовать», «Применить») | +2 |

Максимум 8. Правка или ответ на вопрос у заметки с 0 поднимает её до 2 — выход из «молчания»
через явный интерес, без кнопки «вернуть».

## 6. Что меняется на нуле

- Общая проверка (`ManagerJob`) и проверка по заметкам (`BackgroundAnalysis`) пропускают
  заметку при выборке.
- «Как продвигается?» (`CheckInJob.progressCandidate`) её не выбирает.
- Новые предложения и вопросы по ней не создаются.
- Напоминания, поиск, колоды, обмен — не затрагиваются: это ответственность пользователя,
  а не помощника.

## 7. Интерфейс

- «Настройки → Эксперименты → Баллы внимания помощника» (по умолчанию выключено) с пояснением
  в одну строку: «Помощник реже возвращается к заметкам, которым вы не отвечаете».
- При включённой опции в открытой заметке — строка «Внимание помощника: N из 8» (мелко,
  в блоке метаданных); при нуле — «Помощник больше не работает с этой заметкой. Откройте или
  измените её, чтобы вернуть».
- На карточках в списке баллы не показываем: лишний шум.

## 8. Открытые вопросы

1. Обнулять ли баллы у заметок в корзине/архиве — корзина и так вне проверок, не трогаем.
2. Нужен ли «заморозить внимание» у конкретной заметки (вечные 8) — не в первой версии.
3. Влияние на `DuplicateFinder` и команды заметок — не влияет: команды пользователя явные.
4. Показывать ли в чате помощника, что заметка «замолчала» — не показываем, тихая функция.

## 9. План внедрения

1. SQLite 20 + `notes.attention`, миграция, чистая Java `AttentionPolicy` (правила §§3–5,
   потолки, «не чаще раза в сутки») + JVM-тесты.
2. Точки учёта: создание заметки, «Отклонить», «Использовать/Применить», ответы на вопросы,
   «Как продвигается?», открытие/правка (через `Store`).
3. Фильтры выборок проверок и вопросов (только когда настройка включена).
4. Настройка и строка в заметке.
5. Эмулятор: `CommandStorageTest`-стиль — назначение, списания, пороги, выход из нуля.
