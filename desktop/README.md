# Мимоходом для компьютера (Windows, macOS)

Порт приложения на Tauri 2: ядро на Rust (`core`), оболочка (`src-tauri`), интерфейс на HTML/JS/CSS без сборщика (`ui`). Версия 0.10.3.6 (в `Cargo.toml` и `package.json` — `0.10.3-6`, см. `../docs/DESKTOP.md`): заметки, поиск, папки, картинки, экспорт, тёмная тема, синхронизация с телефоном по Wi-Fi, ИИ-чат через Polza.AI, фоновый помощник (названия и подсказки, напоминания из текста, стопки, автопапки, вопросы о планах) сводки видео YouTube горячие клавиши (Esc закрывает окно, поиск, заметку; список — в настройках), уведомления о напоминаниях, календарь и работа в трее. Протокол — `../docs/SYNC.md`.

## Структура

- `core` — библиотека `mimo-core`: `store` (SQLite + FTS5), `policy` (порты правил из Android: папки, список картинок, поиск, метаданные), `sync` (`crypto`, `engine`, `server`, `client`, `pairing`), `reminders` (напоминания и календарь), `app` и `api::dispatch` (все команды интерфейса).
- `src-tauri` — оболочка: команда `rpc(cmd, args)`, диалог сохранения файла, уведомления, трей, автозапуск, один экземпляр. Переменная окружения `MIMO_DATA_DIR` задаёт другую папку данных (для проверок, чтобы не трогать настоящую базу).
- `ui` — сам интерфейс; в Tauri подключается как `frontendDist`.

Данные лежат в папке приложения пользователя (`app.fastnotes.desktop`): `mimohodom.db` и `images/`.

## Команды

Нужны Rust (stable) и Node 20+.

```bash
npm ci
npm run dev        # окно приложения с перезагрузкой
npm run build      # установщики в target/release/bundle
cargo test -p mimo-core
MIMO_SCALE_N=30000 cargo test -p mimo-core --test scale -- --nocapture   # большой объём (по умолчанию 3000 заметок)
npm run dev:web    # только интерфейс в браузере: http://127.0.0.1:5173 (данные в target/dev-data)
```

Для проверки обмена без телефона: `cargo run -p mimo-core --example headless -- <папка данных>` печатает строку сопряжения и принимает команды (`DUMP`, `ADD название|текст`, `QUIT`); с ним работает `../tests/sync-e2e.cjs`.

## Сеть и брандмауэр

Приложение слушает порт 47616 (TCP, обмен) и 47615 (UDP, поиск компьютера телефоном) только при включённой синхронизации. Брандмауэр Windows при первом запуске спросит разрешение для частных сетей — его нужно дать. Если телефон не находит компьютер, проверьте, что оба в одной сети и точка доступа не изолирует клиентов; адрес также зашит в строку сопряжения.
